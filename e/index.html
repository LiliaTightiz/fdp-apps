How the city works (model, rules and checks)

Network. Ten microgrids on a ring (70 kW links) and a substation bus with three feeders (150 kW each). Grid import is capped at 380 kW, export at 150 kW. Each microgrid has its own solar, load and battery.

Agent rule. Store solar surplus; cover the evening peak from the battery above a 25 % reserve; top up from the grid in the cheap solar window. If the grid is lost, the reserve is used down to the 10 % band. Exploration noise is added, as in a policy that still learns. This rule is illustrative; it is not the QS-MARL model.

shield: b ← clip(b, −P_dis(s), P_ch(s)), 10 % ≤ SoC ≤ 90 %, |flow| ≤ link rating

Safety shield. When ON, every battery action and every link flow is projected onto its limits before it reaches the hardware. When OFF, raw actions are applied and each breach is counted.

Central control centre. One controller sets all batteries and routes energy with an exact max-flow (Edmonds-Karp): local exchange first, then import, then export. If the centre is lost, every unit holds and only the three feeders still serve their own microgrid.

Decentralized agents. Each agent sets its own battery. A microgrid in need sends a request that travels at most 3 links through live neighbours; the first node that can give answers, and energy flows back along that exact path (up to 8 rounds per 15 min). An agent that is down cannot ask, give or relay.

each node: pv − curtail − b + inflow − outflow + unserved = load

Checks. The balance above is audited at every node in every 15-min step; the largest error is about 1e-13 kW. With the shield ON, the count of breaches stays at zero.
