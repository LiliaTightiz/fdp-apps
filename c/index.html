Energy per decision: dense ANN vs SNN actor

Example actor size: 64 inputs, 32 hidden units, 4 actions. A dense ANN does every multiply-accumulate (MAC) at each decision. An SNN does one accumulate (AC) per spike, per synapse, over T time steps.

E_ANN = N_MAC · 4.6 pJ E_SNN = N_AC · 0.9 pJ (45 nm, 32-bit float)

First-order compute estimate after Horowitz (ISSCC 2014). Memory access and the cost of state upkeep on neuromorphic chips are not included, so real gains are smaller. In QS-MARL each microgrid agent runs such an SNN actor at the edge.

Model, equations and checks
τ_m dV/dt = −(V − V_rest) + R·I(t) if V ≥ V_th: spike, V ← V_reset, refractory 2 ms

Leaky integrate-and-fire neuron: τ_m = 20 ms, V_rest = −65 mV, V_th = −50 mV, V_reset = −70 mV. Each input spike lifts V by the synapse weight (delta synapse). Euler step 0.1 ms.

f = 1 / ( t_ref + τ_m · ln[(V∞ − V_reset)/(V∞ − V_th)] ), V∞ = V_rest + R·I

With a steady current the measured rate is compared with this closed form. References: Gerstner, Kistler, Naud and Paninski (2014) Neuronal Dynamics; Maass (1997) Neural Networks 10(9); Horowitz (2014) ISSCC; Balasubramanian (2021) PNAS 118(32) for the 20 W brain.
