# Five live apps for ITSR FDP 2026, Session 04

Class apps for the talk "Quantum-Enhanced Multi-Agent Decision-Making for Autonomous and Resilient Energy Networks" by Dr. Lilia Tightiz, Sejong University.

**Live site:** https://liliatightiz.github.io/fdp-apps/

| App | Episode | Title | Live link |
| --- | --- | --- | --- |
| A | 3 | You Are the Agent | https://liliatightiz.github.io/fdp-apps/a/ |
| B | 4 | Why Selfish Agents Crash the Grid | https://liliatightiz.github.io/fdp-apps/b/ |
| C | 6 | A Brain That Spikes | https://liliatightiz.github.io/fdp-apps/c/ |
| D | 7 | Qubits Pick the Chargers | https://liliatightiz.github.io/fdp-apps/d/ |
| E | 9 and 10 | Agent City Stress Test | https://liliatightiz.github.io/fdp-apps/e/ |

Each app is one self-contained HTML page. It runs in any phone or desktop browser, with no login and no install. All data are synthetic and made for class use.

## Files

- `index.html`: the home page, with links to the five apps
- `a/` to `e/`: one folder per app, each with its own `index.html`
