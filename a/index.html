How the agents decide (model and equations)

State at hour t: battery energy st, the hour, the price, solar and load now, and forecasts for later hours. Action: AC battery power bt in kW (plus is charge). One step is one hour.

grid g_t = load_t − pv_t + b_t s_t+1 = s_t + 0.95·b_t (charge) s_t+1 = s_t + b_t / 0.95 (discharge) cost_t = price_t · g_t if g_t > 0, else ₹3.0 · g_t (export credit)

Limits: 0.6 ≤ s ≤ 6.0 kWh, |b| ≤ 2.5 kW. A safety layer clips any request that breaks a limit. Energy left at 06:00 next day is valued at ₹7.0 per kWh, so an empty battery is not free.

V_t(s) = min_b [ cost_t(s, b) + V_t+1(s') ] (Bellman)

Oracle. One exact linear program over all 24 hours with the true prices, solar and load. It is the best result any agent can reach on this day.

AI agent (MPC). Model predictive control. Each hour the same linear program is solved for the rest of the day, with the true values for this hour and forecasts for later hours. Only the first action is applied. Then the plan is made again.

Self-use rule. Solar surplus charges the battery; any deficit is covered from the battery. No grid charge. This mode is a common factory default.

Checks. The browser LP solver (two-phase simplex, Bland rule) matches the HiGHS solver to 1e-13 ₹ on 40 test days. Over 300 random days the AI reaches 96.5 % of the oracle savings on average and the rule 74 %.

All data are synthetic and illustrative: a ToD-style tariff with a cheap solar window and an evening peak, a 4 kWp roof, a 6 kWh battery. References: Bellman (1957); Rawlings, Mayne and Diehl (2017) Model Predictive Control; Sutton and Barto (2018) Reinforcement Learning.
